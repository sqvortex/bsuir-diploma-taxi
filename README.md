# Viago

Дипломный проект БГУИР: программное средство бронирования мест в межгородских
маршрутных такси по расписанию с прогнозированием свободных мест.

Стек: Python 3.12+, Django 5.2, PostgreSQL 16 (локально пока SQLite), pytest.
План этапов: [docs/plan.md](docs/plan.md).

## Как запустить у себя

```bash
# 1. Создать виртуальное окружение и установить библиотеки
python -m venv .venv
source .venv/bin/activate          # в Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Создать базу данных (файл db.sqlite3) по моделям
python manage.py migrate

# 3. Создать администратора (спросит телефон в формате +375XXXXXXXXX и пароль)
python manage.py createsuperuser

# 4. Загрузить пример: 3 маршрута, автопарк, пользователей всех ролей, рейсы на неделю и брони
python manage.py load_demo

# 5. Запустить сайт и открыть http://127.0.0.1:8000/
python manage.py runserver
```

## Демо-пользователи

Команда `load_demo` создаёт пользователей всех ролей, пароль у всех `demo12345`:

| Телефон | Роль | Что увидит в кабинете |
|---------|------|------------------------|
| +375293333333 | пассажир | свои поездки |
| +375291111111 | водитель | свои рейсы на сегодня и неделю |
| +375292222222 | диспетчер | панель с рейсами дня и загрузкой |

Администратор создаётся командой `createsuperuser` и видит ещё и пользователей по ролям.

## Страницы

| Адрес | Что там |
|-------|---------|
| `/` | главная с поиском и популярными направлениями |
| `/search/` | результаты поиска рейсов со свободными местами на участке |
| `/accounts/register/`, `/accounts/login/` | регистрация и вход по телефону |
| `/cabinet/` | личный кабинет, своё содержимое для каждой роли |
| `/admin/` | админка Django |

## Название и цвета

Название сервиса задаётся одной строкой `SITE_NAME` в `config/settings.py`.
Все цвета собраны в начале файла `static/css/theme.css` (блок `:root`).

## Тесты

## Как устроен код

| Папка | Что внутри |
|-------|------------|
| `config/` | настройки проекта и адреса страниц |
| `accounts/` | пользователь с входом по телефону и ролями |
| `transport/` | остановки, маршруты, автопарк, шаблоны расписания, рейсы |
| `bookings/` | брони мест на участках маршрута |
| `core/` | главная, поиск и личные кабинеты |
| `templates/` | HTML-шаблоны страниц |
| `static/` | стили (`css/theme.css`) и Bootstrap 5 (`vendor/`) |
| `tests/` | автоматические тесты (pytest) |
| `docs/` | план и заметки к пояснительной записке |

## PostgreSQL

Чтобы работать с PostgreSQL вместо SQLite, задайте переменные окружения
`POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT`.
Если `POSTGRES_DB` не задана, используется SQLite.
